# Project Name : Campus-Canteen-Process-Optimization-
Project objective : To eliminate long canteen wait times and counter congestion by redesigning the operational workflow. By replacing the single-queue system with a mobile pre-ordering model, the project aims to reduce student wait times from 18 minutes to under 2 minutes, boost kitchen productivity by 35%, and to manage the work effectively and efficiently

# Tools Used

BPMN Swimlane Mapping : Mapped the "As-Is" queue bottlenecks and designed the optimized "To-Be" mobile workflow.  

Gap Analysis : Identified single points of failure, lack of order visibility, and kitchen delays.  

Process Optimization : Restructured the order, payment, and meal collection steps to cut wait times.

# Project Workflow

1. Current State Analysis (As-Is) : Mapped the existing manual single-queue bottleneck where students faced 18-minute wait times.  

2. Gap Analysis : Identified key root causes, such as delayed order visibility and reactive kitchen cooking.  

3. Future State Redesign (To-Be) : Designed an optimized mobile pre-ordering process using BPMN swimlanes.  

4. Digital Solution Integration : Embedded automated kitchen order previews, pickup notifications, and QR-code express counters.  

5. Impact Evaluation : Measured process improvements (cutting wait times to under 2 minutes and increasing kitchen productivity by 35%).

By transforming the canteen from a single-queue bottleneck into a digital pre-ordering workflow, this project eliminates 18-minute wait times and drops peak delays to under 2 minutes. It serves as a clear, scalable solution for streamlining high-volume campus operations.
