# Project Name : Campus-Canteen-Process-Optimization-
Project objective : To eliminate long canteen wait times and counter congestion by redesigning the operational workflow. By replacing the single-queue system with a mobile pre-ordering model, the project aims to reduce student wait times from 18 minutes to under 2 minutes, boost kitchen productivity by 35%, and double peak-time throughput.

# Tools Used

BPMN Swimlane Mapping : Mapped the "As-Is" queue bottlenecks and designed the optimized "To-Be" mobile workflow.  

Gap Analysis : Identified single points of failure, lack of order visibility, and kitchen delays.  

Process Optimization : Restructured the order, payment, and meal collection steps to cut wait times.
